# RTX Corporation Board of Directors: web sources (`pratt-whitney-board`)

Web research for the board profile of RTX Corporation, the parent of Pratt & Whitney. All searches were run on 2026-10-10 with the WebSearch tool; the container cannot fetch pages, so each web item records what the search summary stated (never a verbatim quote) and the result URL that supports it. A web item counts as corroborated only when a second, differently worded search returned the same fact (`corroborated_by` in `evidence.jsonl`).

The search budget for the session ran out after 24 completed searches (the 25th was refused), below the 25-45 aimed for, leaving nine of the 21 web items without a second search. On 2026-10-10 a second agent re-searched all 21 web items with 22 searches (section 6): all 21 are now corroborated; 19 were kept and 2 corrected (PG-0044, PG-0056); none was dropped.
